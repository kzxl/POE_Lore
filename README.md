## 📖 Giới Thiệu

Trang web tổng hợp toàn bộ **cốt truyện (lore)** của game **Path of Exile** bằng **tiếng Việt**, sắp xếp theo dòng thời gian cụ thể — từ thuở khai thiên lập địa cho đến Path of Exile 2.

**Công nghệ:** Vite + Vanilla JS | Không database — toàn bộ nội dung static

## 🚀 Cài Đặt & Chạy

```bash
# Clone repo
git clone https://github.com/kzxl/POE_Lore.git
cd POE_Lore

# Cài dependencies
npm install

# Chạy dev server
npm run dev

# Build production
npm run build
```
